# Чек-лист на реальном iPhone

Все проверки до сих пор шли в Chromium с вьюпортом iPhone; WebKit в деле не был. Пройти на двух телефонах (свой и один поменьше, SE или 13 mini), отметить, что не так, кинуть сюда список. Каждый пункт — минута.

## Установка и вход

1. Открыть ссылку из беседы ВК внутри приложения ВК. Ожидание: подсказка «Открой ссылку в Safari». Открыть в Safari.
2. В Safari: подсказка «Сначала установи, потом войди» с тремя шагами. Поделиться → На экран «Домой». Иконка Raspison появилась, название не обрезано.
3. Запустить с иконки. Цвет сплеша тёмный (нет белой вспышки). Статус-бар не наезжает на заголовок.
4. Ввести код (можно русской раскладкой и без дефиса) → выбрать себя → PIN. Открылось расписание.
5. Закрыть приложение (свайп вверх), открыть снова — вход не спрашивают. Утром следующего дня — тоже.

## Расписание

6. Неделя → тап по дню → «погружение», назад жестом с левого края возвращает на неделю, не выбрасывает из приложения.
7. Свайп влево/вправо на неделе и на дне листает.
8. Авиарежим → закрыть и открыть приложение: расписание есть, плашка «Офлайн · данные от …». Выключить авиарежим — плашка уходит сама в течение минуты.
9. Экран дня → кнопка «Поделиться» → системное меню с картинкой, отправить себе в Telegram. Картинка в фирменном шрифте.

## Домашка и файлы

10. «+» → написать текст → «Подробнее» → выбрать фото из Фото (HEIC) → превью появилось → Отправить. Фото в карточке открывается на весь экран внутри приложения, закрывается тапом.
11. Приложить PDF из Файлов. Открывается, кнопка «Готово» возвращает в приложение.
12. «Дополнить запись»: клавиатура появилась, поле и кнопка «Добавить» видны при открытой клавиатуре.
13. Долгое нажатие на телефон в Контактах даёт «Скопировать»; на фото доски — «Сохранить изображение».

## Группа и админка

14. Опрос: голос ставится, повторный тап снимает; закрытый опрос голос не принимает и говорит об этом.
15. Анонимный вопрос: отправился, автор не виден.
16. Админка → Расписание → черновик → добавить пару в шторке при открытой клавиатуре → Сохранить → Опубликовать.
17. Админка → Новая неделя → По скану → сфотографировать расписание → распознать → черновик читаем → применить (после подключения Polza).

## Что записать

Модель телефона, версия iOS, номер пункта, что увидел вместо ожидаемого, скриншот. Пункты 3, 9, 12 и 13 — самые вероятные кандидаты на проблемы.
