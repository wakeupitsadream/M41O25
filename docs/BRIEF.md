# Бриф: приложение группы М41О25

Зафиксированные решения по итогам 63 вопросов (см. QUESTIONS.md). Дата: 02.09.2026.

## Продукт

- Боль: расписание, ДЗ и объявления в одном месте. Опросы — важная фича.
- Киллер-фактор: удобство, простота и дизайн. «Красиво и показуемо» важнее скорости запуска.
- Официальный ЛК есть, но учебный отдел туда ничего не грузит — расписание уходит сканом в беседу старост.
- Группа: 21 человек. Запуск сразу на всех, приложение наполнено данными в день запуска.
- Успех: активно пользуется больше половины группы.
- Одна группа («возможно пока что») — мульти-тенант не строим, но group_id в данных закладываем.
- Название: нейтральное, без явного «РАНХиГС», с намёком на учёбу/группу.

## Платформа

- **PWA-сайт**, не Telegram mini app: устанавливается на экран «Домой» на iPhone, ведёт себя как приложение. Причина в т.ч.: в универе плохая связь, Telegram — через VPN, основной чат группы в ВК.
- Хостинг: Vercel. Автодеплой из GitHub сразу. Отдельный сервер в РФ не нужен.
- Пишем с нуля, наработки DailyK не переиспользуем. Всё кодом, без n8n.
- Vision API: PolzaAI (есть доступ).
- Офлайн-кеш последнего расписания обязателен. Тёмная тема. Десктоп — необязателен.
- Уведомления/пуши в v1 — никакие.

## Расписание

- Источник: скан подписанного документа с расписанием **всех групп**, приходит еженедельно (сб-вс, изредка пт) на следующую неделю.
- Пайплайн: загрузка скана → распознавание vision-моделью (только группа М41О25) → черновик → ручная правка → публикация. Ручной ввод/правка — обязательная возможность.
- Правит только админ. Замены в день занятий редки — точечная ручная правка.
- Верхняя/нижняя недели есть. Подгрупп нет. Преподаватели и кабинеты — отдельные поля (есть на скане).
- Виды: семестр → неделя (первый экран) → день. Навигация «в глубину» с анимацией погружения.
- Расписание сессии приходит за 1–3 дня до неё (~через 3 месяца) — формат «пары по датам» закладываем сразу, UI позже.

## Домашка

- Гибрид: быстрый текст за 20 секунд на паре ИЛИ оформленная карточка (предмет, дедлайн, описание, вложения).
- Привязка к предмету/паре. Вложения: фото и файлы. Добавляют все.
- Дубли: отметка «дубль». После дедлайна — автоархив.
- Личная галочка «сделал»: в настройках, не афишируется.
- Вики-правки: любой может править чужое, правка помечается аватаркой/маркером автора правки, его текст — другим цветом из палитры.
- Справочник предметов вбивается один раз из расписания.

## Разделы (все в v1)

- Новости: объявления (дубль ВК-канала руками), постит только админ/модератор, закреп важного.
- Задачи: «сдать деньги до пятницы», чек-лист «кто сдал», отмечает только админ.
- Опросы-голосования.
- Контакты преподавателей и деканата. Дни рождения. Анонимные вопросы.
- Лента «что нового с последнего захода» (in-app, вместо пушей). Полноценный чат — под вопросом (риск дублировать ВК), решаем позже.
- Поиска нет — хватает фильтра по предмету.

## Доступ и роли

- Посторонний видит «нет доступа».
- Роли: админ (Максим) + модератор (староста) + студенты.
- Профиль: имя/ник вручную, минимум персданных.
- Отчисленных удаляет админ руками, их записи остаются.
- Модерация: rate limit ~15 комментариев/час + удаление админом. Банов нет.
- Анонимные вопросы — анонимность реальная.

## Эксплуатация

- Работает само неделями (сессия у админа). Каникулы — «спит» как есть.
- Семестры храним архивом. Бэкап раз в 1–3 суток. Потеря данных неприятна, но не катастрофа.
- Вместо мониторинга — маленькая админка со сводкой основных данных.

## Ресурсы

- 5–7 ч/нед по худшей неделе, до 2 ч/день в хорошие. Проект приоритетный.
- Запуск «когда готово», все разделы сразу, перед запуском — наполнение данными.
