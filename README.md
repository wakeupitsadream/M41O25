# Raspison

Приложение группы М41О25 (РАНХиГС, Оренбург): расписание с распознаванием скана, домашка, новости, задачи, опросы, контакты, дни рождения, анонимные вопросы. PWA — ставится на экран «Домой» iPhone, расписание работает офлайн.

Документы планирования: `docs/PLAN.md` (архитектура, роадмап), `docs/BRIEF.md` (решения), `docs/QUESTIONS.md`.

## Стек

Next.js 15 (App Router) · Tailwind 4 · Motion · Drizzle + Postgres (Neon) · Cloudflare R2 (файлы) · PolzaAI (vision-модель для скана) · Serwist (service worker) · Vercel.

## Локальный запуск

```bash
npm install
cp .env.example .env.local        # DATABASE_URL на локальный Postgres, OCR_MOCK=1
npm run db:migrate                # применить миграции
npm run db:seed -- --demo         # группа + админ + 20 тестовых студентов + расписание
npm run dev                       # http://localhost:3000
```

Вход: код `M41-2025` → «Батутин Максим» → придумать PIN. Иконки PWA: `npm run icons`.

Проверка экранов на iPhone-вьюпорте (нужен запущенный dev-сервер): `npm run e2e` — скриншоты в `OUT` (по умолчанию scratchpad), сценарии в `e2e/*.mjs`.

## Развёртывание (один раз, ~40 минут)

Проект на Vercel уже создан (`raspison`, привязан к этому репозиторию: каждый push собирает деплой, защита превью-ссылок отключена — у приложения свой вход). Осталось дать ему базу, хранилище и секреты.

1. **Neon** (neon.tech, free, регион Frankfurt — рядом с `fra1` из `vercel.json`) → создать проект → скопировать строку подключения **с `-pooler`** → `DATABASE_URL`.
2. **Cloudflare R2** (free 10 ГБ) → создать бакет `raspison` → API-токен с правами Object Read & Write → `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET`. Без этих переменных на Vercel загрузка файлов отвечает понятной ошибкой «хранилище не подключено», а ежедневный бэкап пропускается — всё остальное работает.
3. **PolzaAI** (polza.ai) → пополнить на 100 ₽ → ключ → `POLZA_API_KEY`. Модели: `OCR_MODEL=google/gemini-3.5-flash`, `OCR_MODEL_STRONG=anthropic/claude-sonnet-5` (проверь актуальные id в каталоге polza.ai/models). Не задавать `OCR_MOCK` в проде.
4. **Секреты**: `AUTH_SECRET`, `ANON_PEPPER`, `CRON_SECRET` — `openssl rand -base64 32` для каждого.
5. **Vercel → Settings → Environment Variables** (отметить и Production, и Preview): `DATABASE_URL`, `AUTH_SECRET`, `ANON_PEPPER`, `CRON_SECRET`, `APP_TZ` и `NEXT_PUBLIC_APP_TZ` (= `Asia/Yekaterinburg`), `POLZA_API_KEY`, `OCR_MODEL`, `OCR_MODEL_STRONG`, `R2_*`. Плюс на первый запуск: `SEED_ADMIN_NAME="Фамилия Имя"` и `SEED_INVITE_CODE=M41-XXXX-XXXX` (без него код сгенерируется случайно и будет виден только в логе сборки). Миграции применяет production-сборка; preview-сборки базу не трогают (черновая ветка не может сломать прод), если только не задан `MIGRATE_ON_BUILD=1`.
6. **Deployments → последний деплой → Redeploy.** Сборка на Vercel применяет миграции к базе из `DATABASE_URL` (production всегда, preview только с `MIGRATE_ON_BUILD=1`) и при заданном `SEED_ADMIN_NAME` создаёт группу и админа (повторные сборки ничего не дублируют). После первого входа `SEED_*` можно удалить.
7. **Первый вход**: открыть `/enter`, ввести код, выбрать себя, задать PIN → Профиль → Админка.
8. **Наполнение** (Админка): Люди — добавить 21 одногруппника; Предметы — справочник с преподавателями и аудиториями; Семестры — даты семестра и сессии; Настройки — время пар и инвайт-код; Расписание → Новая неделя → «По скану» или вручную → Опубликовать.
9. Кинуть в беседу группы ссылку и инвайт-код. Домен оставить `*.vercel.app` (кастомные домены Vercel из РФ блокируются РКН по IP).

Production-ветка проекта — `main`: push в неё собирает и выкатывает `raspison.vercel.app` (миграции применяются автоматически). Пока код живёт в `claude/classmate-app-planning-ypgy29`, каждый push собирает preview (адрес вида `raspison-git-<ветка>-<команда>.vercel.app`), а на production новый коммит попадает через мерж в `main` или Deployments → ⋯ → Promote to Production. Правила для разработки — в `CLAUDE.md`, действия при сбое — в `docs/RUNBOOK.md`, проверка на телефоне — в `docs/DEVICE-CHECKLIST.md`. Cron из `vercel.json` (23:00 UTC = 04:00 по Оренбургу) подхватывается автоматически; Vercel сам передаёт `CRON_SECRET` в заголовке `Authorization`.

## Еженедельный ритуал (суббота, 10 минут)

Админка → Новая неделя (дата и чётность уже подставлены) → «По скану» → 1–3 фото скана → Распознать → проверить подсвеченные ячейки → Применить → при необходимости поправить тапом → Опубликовать. Замены в день занятий — тап по паре в редакторе опубликованной недели.

## Бэкапы

Ежедневно cron складывает `backups/YYYY-MM-DD.json.gz` в R2 (храним 30). Восстановление в пустую базу: `npm run db:migrate && npm run db:restore -- ./2026-09-02.json.gz`. Файлы-вложения не бэкапятся. В дамп не попадают PIN-хеши, сессии и квоты анонимных вопросов: после восстановления все входят заново по инвайт-коду и задают PIN.

## Защита входа

Инвайт-код — формат `М41-XXXX-XXXX` (~40 бит), меняется кнопкой в настройках. PIN: после 5 неверных попыток профиль блокируется на 1 минуту, затем 5, 30 минут и сутки; по IP — не больше 60 неудачных попыток за 10 минут (группа за одним NAT вуза). Свой PIN админ сбросить не может (чтобы профиль админа нельзя было занять) — если забыл, сбрасывает второй админ или напрямую в базе: `update users set pin_hash = null where id = '…'`. Сессия устройства живёт год, cron чистит отозванные.

## Роли

- **Админ** — всё: расписание, люди, предметы, отметки «кто сдал», удаление чего угодно.
- **Староста (модератор)** — новости, задачи, контакты, ответы на анонимные вопросы, закрытие опросов.
- **Студент** — ДЗ (создание, дополнение блоком, комментарии, «дубль»), опросы, реакции, анонимные вопросы. Лимит: 15 создающих действий в час.

## Статус реализации (02.09.2026)

Проведено шестистороннее ревью кода с адверсариальной проверкой находок; подтверждённые исправлены (см. историю коммитов). Готово и проверено локально (Playwright на вьюпорте iPhone, production-сборка, офлайн-режим): вход по инвайт-коду и PIN, расписание (неделя → день → семестр, «Сейчас идёт», офлайн-кеш), админка (недели, редактор пар, публикация, замены, люди, предметы, семестры, настройки), OCR-пайплайн (в тестовом режиме — без реального скана), домашка (быстрая форма, вложения, правки-блоки, комментарии, «дубль», личные галочки, архив), новости, задачи с чек-листом, опросы, контакты, дни рождения с конфетти, анонимные вопросы, лента «Что нового», ежедневный бэкап, иконки и подсказка установки.

Пострелизные фичи, уже включённые: рулетка «Кто отвечает» (/group/roulette), погода к ближайшей паре на экране недели (Open-Meteo, Оренбург), PNG-карточка дня для шаринга в ВК/Telegram (кнопка на экране дня).

Не проверено на реальных данных: распознавание настоящего скана через PolzaAI (нужен ключ и фото документа), работа с R2 (нужны ключи), установка PWA на физическом iPhone, строка погоды (Open-Meteo недоступен из среды разработки; при недоступности сервиса строка просто не показывается). Отложено: тепловая карта семестра, стрик, итоги семестра, пасхалки.
