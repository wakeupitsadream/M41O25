# Помощник по учёбе в MAX

Личный бот в мессенджере MAX: решает задачи по фото и тексту, проверяет решения, делает конспекты, понимает голосовые и просто болтает. Работает на **бесплатных** моделях: основная — самая сильная бесплатная (Gemini), остальные подхватывают, когда у неё кончился дневной лимит. Отвечает только владельцу.

Отдельный проект Vercel с Root Directory = `max-bot`, со своими зависимостями и CI (`.github/workflows/max-bot.yml`). Raspison эту папку не собирает и не проверяет.

## Что умеет

| | |
|---|---|
| Режимы (`/mode`) | 🧮 Решатель — решение по шагам, ответ сверху, проверка · 🧑‍🏫 Репетитор — подсказки вместо готового ответа · 🎓 Билет — «устно за 30 секунд», план, термины, доп. вопросы · 💬 Болталка — на «ты» и с юмором |
| Фото без подписи | бот не тратит запрос, а предлагает: Решить · Проверить решение · Конспект · Текст с фото · Обсудить. Несколько фото подряд или альбомом собираются в одну пачку |
| Несколько заданий на фото | список найденных заданий и кнопки «Все по порядку / 1 / 2 / …» |
| Подпись к фото | действие по смыслу: «проверь» — проверка, «конспект», «перепиши текст»; иначе — как в текущем режиме |
| Голосовые | распознаются (Groq Whisper или Gemini), текст показывается, дальше — обычный ответ |
| Кнопки под ответом | ✂️ Короче · 🔍 Подробнее · 🙂 Проще · 🧠 Проверь меня (3 вопроса + кнопка «Ответы») · 🆕 Заново · ⚙️ Режим; у репетитора — «Покажи решение» |
| Контекст | помнит текущую тему (последние сообщения + сжатое резюме старых), понимает ответ на конкретное сообщение и пересланные; `/new` — новая тема |
| Формулы | MAX не рисует LaTeX, поэтому ответ модели проходит через конвертер: `\frac{a}{b}` → a/b, `x^2` → x², `\sqrt{x}` → √x |
| Профиль (`/profile`) | курс и направление + предметы из Raspison (если подключён) — модель видит их в каждом запросе |
| `/status` | какие модели доступны, у каких кончился лимит и когда вернутся |

## Запуск (один раз, ~10 минут)

1. **Проект Vercel** `max-bot` уже создан и смотрит на этот репозиторий, Root Directory — `max-bot`. Если его нет: Vercel → Add New → Project → репозиторий `m41o25` → Root Directory `max-bot` → Framework Preset «Other».
2. **База.** Vercel → проект `max-bot` → Storage → Create Database → **Neon** (Free) → Connect to project. Переменная `DATABASE_URL` появится сама. Таблицы бот создаёт сам при первом запросе.
3. **Переменные** (Settings → Environment Variables, окружение **Production**):
   - `MAX_BOT_TOKEN` — токен бота из MAX (Master Bot или бизнес-кабинет);
   - ключи моделей — минимум `GEMINI_API_KEY`, лучше ещё 2–3 запасных. Где взять бесплатно — [docs/MODELS.md](docs/MODELS.md).
4. **Redeploy** (Deployments → ⋯ → Redeploy) — переменные подхватываются только новой сборкой.
5. Открыть `https://<адрес-проекта>.vercel.app/api/health` — ответ `"ok": true`, `"webhook": { "state": "registered" }`. Health сам подписывает бота на вебхук; дальше это повторяет ежедневный cron.
6. В MAX открыть бота и прислать **последние 6 символов токена** — бот привяжется к тебе. Чужим он отвечать не будет. (Можно вместо этого задать `MAX_OWNER_ID`.)

## Переменные окружения

| Переменная | Нужна | Что делает |
|---|---|---|
| `MAX_BOT_TOKEN` | да | токен бота; из него же выводится секрет вебхука |
| `DATABASE_URL` | да | Postgres (Neon). Появляется сам при подключении Neon в Storage |
| `GEMINI_API_KEY` | очень желательно | основная модель (Gemini 3.5 Flash и семейство) |
| `GROQ_API_KEY`, `MISTRAL_API_KEY`, `OPENROUTER_API_KEY`, `GITHUB_MODELS_TOKEN`, `CEREBRAS_API_KEY`, `CLOUDFLARE_API_TOKEN` + `CLOUDFLARE_ACCOUNT_ID` | нет | запасные бесплатные модели; Groq ещё и распознаёт голос. Подробно — `docs/MODELS.md` |
| `MAX_OWNER_ID` | нет | id владельца в MAX вместо привязки кодом |
| `CHAIN_SOLVE`, `CHAIN_VISION`, `CHAIN_CHAT`, `CHAIN_LIGHT`, `CHAIN_TRANSCRIBE` | нет | свой порядок моделей: `gemini:gemini-3.5-flash,groq:openai/gpt-oss-120b`. Модель не из каталога — с флагами: `openrouter:vendor/model:free#vision` |
| `RASPISON_URL`, `RASPISON_BOT_KEY` (+ `RASPISON_GROUP`, если групп несколько) | нет | профиль: предметы группы из Raspison (`https://raspison.vercel.app` и тот же ключ, что `BOT_API_KEY` в Raspison) |
| `STUDY_START_YEAR` | нет | год поступления для «N курс» в профиле, по умолчанию 2025 |
| `CRON_SECRET` | нет | если задан, `/api/cron` принимает только запросы Vercel Cron |
| `APP_TZ` | нет | часовой пояс, по умолчанию `Asia/Yekaterinburg` |
| `MAX_API_URL`, `MAX_WEBHOOK_SECRET`, `PUBLIC_URL` | нет | переопределения: адрес Bot API (по умолчанию `https://platform-api2.max.ru`), секрет и адрес вебхука |

## Как устроено

- `api/webhook.ts` — вход событий MAX. Проверяет секрет `X-Max-Bot-Api-Secret`, сразу отвечает 200 и думает в фоне (`waitUntil`, до 300 с на Hobby): иначе MAX повторил бы событие. Повторы отсекаются по id сообщения/нажатия.
- `src/llm/` — модели: Gemini через родной API (точно различает дневную и минутную квоту, принимает голос), остальные — через OpenAI-совместимый. Роутер идёт по цепочке (`src/llm/catalog.ts`), пропускает модели без ключа и без зрения, а после лимита ставит модель на паузу до сброса квоты (Gemini — полночь по Лос-Анджелесу, это 12:00 по Екатеринбургу, с ноября — 13:00).
- `src/text/` — LaTeX → Unicode, markdown → HTML для MAX (только b/i/s/code/pre/a), нарезка длинных ответов на сообщения до 4000 символов.
- `src/bot/` — сценарии: владелец, режимы, фото, голос, кнопки, команды, профиль.
- `src/db/` — Postgres: история по темам, режим, ожидающие фото, состояние моделей, дедупликация. Схема создаётся сама.
- `api/health.ts` — проверка без секретов + регистрация вебхука; `api/cron.ts` — ежедневно: вебхук, чистка старого, предметы из Raspison.

Данные: история хранится 180 дней. Текст и фото уходят провайдерам моделей (Google и др.) — на бесплатных тарифах они могут использовать запросы для обучения, поэтому паспорта и чужие персональные данные боту не отправлять.

## Разработка

```bash
cd max-bot
npm ci
npm run typecheck
TEST_DATABASE_URL=postgres://postgres:postgres@127.0.0.1:5432/maxbot_test npm test
```

Тесты — `node:test` через tsx: unit (формулы, разметка, классификация ошибок, роутер) и сценарии бота целиком на настоящем Postgres с подставными MAX и Gemini (`src/bot/bot.test.ts`). Отладка в проде — `/status` в боте, `/api/health` и Vercel → Logs (одна JSON-строка на событие, без токенов и ключей).
