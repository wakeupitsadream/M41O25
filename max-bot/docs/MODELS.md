# Бесплатные модели и ключи (октябрь 2026)

Бот работает только на бесплатных тарифах. Основные модели — Gemini. Остальные провайдеры — запасные: подхватывают, когда у Gemini кончился дневной лимит, когда Google не отвечает или когда нужен голос. Под каждым ответом подписано, какая модель отвечала, а команда `/status` показывает, что сейчас доступно и когда вернутся модели на паузе.

Минимум для работы — `GEMINI_API_KEY`. Рекомендую ещё Groq (голосовые) и Cloudflare (аккаунт уже есть ради R2). Остальное — по желанию.

| Переменная в Vercel | Провайдер | Что даёт боту | Бесплатный лимит | Регистрация из России |
|---|---|---|---|---|
| `GEMINI_API_KEY` | Google AI Studio | Gemini 3.8, 3.7, 3.6, 3.5 Flash — решение задач и фото; 3.5 Flash-Lite — конспект, текст с фото, болталка; Gemma 4 | около 20 запросов в сутки на **каждую** Flash (вместе около 80), около 500 у Flash-Lite | через VPN, вход существующим Google-аккаунтом |
| `GROQ_API_KEY` | Groq | Whisper — голосовые; GPT-OSS 120B — сильный текст и математика; Qwen 3.8 27B — фото | около 1000 запросов в сутки на модель, 8 000 токенов в минуту; Whisper — 2000 в сутки | через VPN, карта и телефон не нужны |
| `CLOUDFLARE_API_TOKEN` + `CLOUDFLARE_ACCOUNT_ID` | Cloudflare Workers AI | Gemma 4 26B с фото, запасной Whisper | 10 000 «нейронов» в сутки (~150 запросов с фото) | аккаунт уже есть (R2), панель — через VPN |
| `ZAI_API_KEY` | Z.ai | GLM-4.6V Flash (фото), GLM-4.7 Flash (текст) | без опубликованных лимитов, примерно один запрос одновременно | по почте, блокировок не найдено |
| `OPENROUTER_API_KEY` | OpenRouter | Gemma 4 31B и другие `:free` | 50 запросов в сутки на весь аккаунт | по почте или через Google; пополнить из России нельзя |
| `MISTRAL_API_KEY` | Mistral | Mistral Medium и Small с фото | лимиты видны только в консоли | нужен SMS-код, номер +7 может не пройти |

После добавления любой переменной: Vercel → проект `max-study-bot` → Deployments → ⋯ у последнего → **Redeploy**. Без этого переменные не подхватятся.

## Google Gemini — основной

1. Включи VPN: AI Studio не открывается с российских адресов.
2. Открой https://aistudio.google.com/apikey под **существующим** Google-аккаунтом: новые аккаунты с номером +7 с 2024 года создаются плохо.
3. Нажми **Create API key**, и проект создастся сам. Ключ с мая 2026 начинается с `AQ.`, так и должно быть.
4. Vercel → Settings → Environment Variables → `GEMINI_API_KEY`, окружение Production → Redeploy.
5. Свои точные квоты Google показывает на https://aistudio.google.com/rate-limit (публичную таблицу он больше не ведёт).

Что важно знать:

- **Квота у каждой модели своя.** Поэтому бот идёт по цепочке 3.8 → 3.7 → 3.6 → 3.5 Flash: у каждой около 20 запросов в сутки. Когда кончаются все четыре, решает GPT-OSS у Groq (для текста), затем Qwen и Flash-Lite (для фото).
- **Сброс суток — в полночь по тихоокеанскому времени.** Это 12:00 по Екатеринбургу, после 1 ноября — 13:00. Если потратить лимит вечером, утром на паре сильных моделей не будет до обеда; бот скажет об этом в `/status`.
- **Gemini 2.5 и все Pro-модели недоступны.** 2.5 закрыт для новых проектов, Pro с апреля 2026 не входит в бесплатный тариф.
- **Если ключ «не принят».** В сентябре часть новых бесплатных проектов Google помечал как Restricted (ошибка 403). Тогда создай ключ в другом проекте той же кнопкой.
- **Данные.** На бесплатном тарифе Google использует запросы для улучшения моделей, их могут читать люди. Паспорта и чужие персональные данные в бот не отправлять.
- **Правила.** Условия Gemini API разрешают пользоваться им только из поддерживаемых стран, а Россия в их число не входит. Сервер бота стоит в США, но формально это всё равно нарушение условий, и проект могут ограничить. Для личного бота риск небольшой, и на этот случай нужны запасные провайдеры.

## Groq — голосовые и запасные модели

1. VPN: Groq блокирует российские адреса.
2. https://console.groq.com → войти через Google, GitHub или почту (карта и телефон не нужны).
3. **API Keys → Create API Key** → в Vercel как `GROQ_API_KEY` → Redeploy.

Бот берёт у Groq `whisper-large-v3-turbo` и `whisper-large-v3` для голосовых (понимают ogg и m4a с iPhone), `openai/gpt-oss-120b` и `gpt-oss-20b` для текста и `qwen/qwen3.8-27b` для фото (до 3 фото за раз). Лимит у Groq — 8 000 токенов в минуту, поэтому для его моделей бот сам укорачивает старую часть разговора. Данные API Groq для обучения не использует.

## Cloudflare Workers AI — запасное зрение и голос

Аккаунт Cloudflare уже есть: в нём лежит R2 для Raspison.

1. С VPN открой https://dash.cloudflare.com (в России Cloudflare замедляют).
2. **Account ID** показан на главной странице аккаунта справа и в адресе страницы → `CLOUDFLARE_ACCOUNT_ID`.
3. Профиль (справа вверху) → **API Tokens → Create Token** → шаблон **Workers AI** → Continue → Create → скопировать → `CLOUDFLARE_API_TOKEN`.
4. Redeploy.

Модели: `@cf/google/gemma-4-26b-a4b-it` (фото, примерно 150 запросов в день), `@cf/meta/llama-4-scout-17b-16e-instruct` и `@cf/openai/whisper-large-v3-turbo`. Лимит общий: 10 000 нейронов в сутки, сброс в 00:00 UTC (05:00 по Екатеринбургу).

## Z.ai — без VPN

1. https://z.ai → регистрация по почте.
2. Раздел API Keys → Create → `ZAI_API_KEY` → Redeploy.

Бесплатные модели: `glm-4.6v-flash` (видит фото) и `glm-4.7-flash`. Лимиты Z.ai не публикует, но одновременно обрабатывается примерно один запрос. Как запасной вариант подходит.

## OpenRouter — 50 запросов в сутки

1. https://openrouter.ai → Sign in.
2. **Keys → Create Key** → `OPENROUTER_API_KEY` → Redeploy.

На все модели с суффиксом `:free` вместе приходится 50 запросов в сутки (сброс по UTC). Поднять лимит до 1000 можно только пополнением на $10, а российские платежи OpenRouter не принимает с мая 2026. Часть бесплатных провайдеров на OpenRouter пишет запросы для обучения.

## Mistral — если пройдёт SMS

1. https://console.mistral.ai → регистрация с подтверждением телефона по SMS (номер +7 может не принять).
2. Тариф **Experiment** (бесплатный) → API Keys → Create new key → `MISTRAL_API_KEY` → Redeploy.

На бесплатном тарифе запросы идут в обучение.

## Чего нет и почему

- **GitHub Models** — закрыт для всех 30.07.2026.
- **Cerebras** — с 16.07.2026 не бесплатен (только платный пробный период с картой).
- **NVIDIA NIM** — не принимает номера +7 для подтверждения.
- **Gemini 2.5, Gemini Pro** — закрыты для новых проектов или платные.
- **GigaChat** — бесплатный тариф для физлиц есть и с Россией не конфликтует. Но нужны Сбер ID, российский корневой сертификат и отдельный, не OpenAI-совместимый клиент. Можно добавить следующим шагом, если зарубежные провайдеры начнут отваливаться.

## Свой порядок моделей

Цепочки по умолчанию — в `src/llm/catalog.ts`. Порядок переопределяется без кода переменными `CHAIN_SOLVE` (задачи и проверка), `CHAIN_VISION` (конспект, текст с фото, распознавание заданий), `CHAIN_CHAT`, `CHAIN_LIGHT` (короче, проще, вопросы, резюме) и `CHAIN_TRANSCRIBE`. Формат — `провайдер:модель` через запятую, например `CHAIN_CHAT=groq:openai/gpt-oss-120b,gemini:gemini-3.5-flash-lite`. Модель не из каталога указывается с флагами: `openrouter:vendor/model:free#vision` (видит фото), `#think` (рассуждающая).

Если Google переименует или уберёт модель, бот получит 404, поставит её на паузу на 6 часов и перейдёт к следующей. В `/status` это видно как «модель недоступна».
