# max-exam-bot

Учебный ассистент в мессенджере MAX: принимает текст, фото и файлы, отвечает структурированно на билеты и задачи, ведёт личную базу конспектов (RAG) и подписки.

План, стек, финмодель и этапы — в [docs/PLAN.md](docs/PLAN.md). Пресеты предметов на семестр — в [config/subjects.json](config/subjects.json).

Статус: планирование. Код появится на этапе 0 (см. план).
